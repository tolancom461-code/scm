# إدارة المشاريع وسلاسل الإمداد — PSCM

Project & Supply Chain Management

تطبيق واحد بواجهة عربية وإنجليزية وأردية، وقاعدة MySQL واحدة. النطاق الحالي: تهيئة الشركة والمشاريع، الموردون والمقاولون، العقود وبنودها، فحص الأعمال FIR، المستخلصات واعتمادها، متابعة الدفعات والمصروف والضمان المحتجز.

دورة العمل: مشروع ← عقد ← فحص أعمال مقبول ← مستخلص ← اعتماد ← تسجيل الصرف الفعلي ← تسليم نهائي وضمان. يصدر المحاسب سند الصرف من برنامجه المحاسبي ثم يسجل رقمه والمبلغ والتاريخ هنا. مدة الضمان بالأيام.

## التشغيل

يتطلب Node.js 22.13 أو أحدث وMySQL متوافقًا مع Drizzle، واتصال TLS موثوقًا بقاعدة البيانات. تضبط `DATABASE_URL` و`JWT_SECRET` و`PORT=3050` في `.env`. يمكن تعيين `FILE_STORAGE_DIR` للمرفقات؛ الافتراضي `.data/documents`.

```powershell
pnpm install --frozen-lockfile
pnpm db:migrate
pnpm db:initialize-projects
pnpm dev
```

لنسخة التشغيل المبنية:

```powershell
pnpm build
pnpm start
```

الرابط: http://localhost:3050/

عند قاعدة جديدة تمامًا ينشأ حساب المالك من شاشة التهيئة الأولى. الحسابات الموجودة لا تتغير عند التشغيل أو الترحيل. يمكن إنشاء حساب إداري إضافي عبر `pnpm admin:create` فقط عند الحاجة، بمتغيرات `ADMIN_USERNAME` و`ADMIN_PASSWORD` و`ADMIN_NAME`.

## الصلاحيات والبيانات

جميع إجراءات API تمر بمركز السياسات، وتُرفض الإجراءات غير المسجلة. اختيار الدور يحمّل قالب صلاحيات يمكن تخصيصه لكل مستخدم مع نطاق مشاريعه. مدير المشاريع يملك الوظائف التشغيلية دون إدارة المستخدمين أو مركز الصلاحيات. صلاحيات الواجهة لا تغني عن فحص الخادم.

الترقيم مركزي للمشاريع والعقود والمستخلصات والفحص، ويتضمن السنة والشهر وتسلسلًا سنويًا مستقلًا لكل نوع. تُحمى عمليات الحفظ من التكرار بمفتاح للعملية ومعاملات قاعدة البيانات.

## التحقق والصيانة

```powershell
pnpm check
pnpm check:dependencies
pnpm test
pnpm test:integration
pnpm db:backup
```

اختبارات التكامل تنشئ سجلات اختبار مؤقتة وتنظفها؛ شغّلها في بيئة التطوير أو الاختبار. فحص المراجع يرصد الملفات غير المرتبطة بالبرنامج أو أدواته، والواردات المحلية المفقودة والحزم غير المعلنة.

النسخ الاحتياطية مشفرة في `.data/backups` وتشمل مخطط القاعدة والسجلات والمرفقات المحلية. يلزم الاحتفاظ بـ`JWT_SECRET` وقت النسخ لفكها، أو قيمة `DATABASE_URL` إن لم يكن السر مضبوطًا. مجلد `.data` غير منشور عبر السيرفر وغير مضاف إلى Git.

انظر [تفاصيل التوحيد](docs/system-unification.md) و[فحص الأعمال FIR](docs/work-inspections-fir.md).
