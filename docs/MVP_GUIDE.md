# دليل النسخة المبسطة — Procure Nexus

هذا دليل الدورة السابقة. الواجهة الافتراضية منذ 11 أكتوبر 2026 هي «المشاريع والمستخلصات»، ودليلها الحالي في [PHASE_ONE_GUIDE.md](PHASE_ONE_GUIDE.md). يمكن فتح الدورة الموصوفة هنا من «الدورة السابقة».

تاريخ النطاق: 8 أكتوبر 2026. هذه نسخة لتجربة إدارة المشاريع والشراء والتوريد والدفعات في دورة واحدة. ليست اكتمالًا لمهمة SCM الشاملة السابقة، ولا نظام محاسبة عامة أو تحويلات بنكية.

## ما الذي تعمل به الآن؟

1. مشاريع مرتبطة بالفروع، مراحل WBS، بنود ميزانية ومراجعات اعتماد.
2. موردون ومواد وخدمات ووحدات قياس ومواقع ومستودعات.
3. أوامر مباشرة للمواد أو الأعمال، مع مرجع العقد وشروطه، بنود وكميات وأسعار وضريبة وموافقات.
4. استلام وفحص مواد جزئي أو كامل، مرتجعات، ومحاضر إنجاز للمقاولين.
5. فواتير ومطابقة واعتماد، جدول دفعات ومقدمات وتسويتها واحتجاز وإشعارات دائنة.
6. متابعة الميزانية والالتزام والاستلام والتكلفة والفواتير والمدفوع والمتبقي والتأخر، ومرفقات وسجل إجراءات.

دورة طلب الشراء وRFQ والعروض والترسية متاحة من زر الدورة المتقدمة. الشراء المباشر لا يتطلب إدخال عرض أو ترسية صوريين.

## تشغيل المشروع

يتطلب Node.js وحزم المشروع و`DATABASE_URL` لقاعدة MySQL/TiDB. القاعدة الحالية رُحّلت والسيناريو التدريبي زُرع بالفعل.

```powershell
npm run db:migrate
npm run db:seed
npm run db:demo
npm run dev
```

`db:seed` يضيف البيانات المرجعية، و`db:demo` ينشئ المشروع التدريبي. إعادة تشغيله مع بقاء ملف الحسابات والمشروع لا تكرر المشروع. لا تحذف ملف الحسابات بهدف إعادة الزرع. عند خلو القاعدة من المستخدمين أنشئ المسؤول من شاشة التأسيس أولًا، أو استخدم `admin:create` بإعدادات `ADMIN_USERNAME` و`ADMIN_PASSWORD` وفق README.

بيانات الدخول التدريبية محفوظة محليًا في `.mvp-demo-credentials.json`. يحتوي الملف على كلمة مرور عشوائية وثلاثة حسابات: المشتري والمستلم والمعتمد. هذه الحسابات إدارية للتدريب؛ استخدم مستخدمين بصلاحيات محددة للتشغيل الفعلي. لا ترسل الملف إلى مستودع أو طرف آخر.

## تجهيز دورة العمل

من «البيانات المرجعية»، أدخل الفرع والموقع والمستودع والصنف ووحداته أولًا. صنف المواد يستخدم أمر مواد، وصنف الخدمة يستخدم عقد أعمال.

من «المستخدمون والصلاحيات» جهز ثلاثة مستخدمين على الأقل. يحتاج المشتري إلى صلاحيات عرض البيانات المرجعية والمشاريع والموردين ودورة الشراء وإنشاء الأوامر. يحتاج المستلم إلى عرض الأوامر والمخزون والاستلام وإنشاء الاستلام والفحص. يحتاج المسؤول المالي إلى عرض الفواتير وإنشائها وطلبات الدفعات؛ يملك المعتمد المناسب صلاحية اعتماد نوع المستند وعرض تاريخ الموافقات. يحدد المسؤول الصلاحيات التفصيلية من الكتالوج المتاح في الشاشة.

من «مسارات الموافقات»، أنشئ مسارات الميزانية وأمر الشراء والفاتورة والدفع ومحضر الإنجاز، وأضف الإشعار الدائن والإفراج عن الاحتجاز عند الحاجة. حدد العملة والإدارة والنطاق المالي والمعتمدين. يجب أن يغطي النطاق قيمة المستند؛ الحد الأعلى غير شامل. الإدارة `*` تعني جميع الإدارات. مسارات المشروع التدريبي مرتبطة بإدارته التي يطابق رمزها رمز المشروع `MVP-…`.

فصل الواجبات مفروض على الخادم حتى للحساب الإداري: منشئ المستند لا يعتمد مستنده، وبعض المستندات المالية تمنع مشتري الأمر ومستلمه أو مثبت شرط الدفعة من اعتمادها. وجود الصلاحية وحدها لا يلغي هذه القواعد.

## خطوات إنشاء مشروع فرع

### 1. المشروع والميزانية

أنشئ المشروع من «المشاريع والميزانيات»، واختر الفرع والعملة والفترة. أضف مراحل مثل البناء والتشطيب والتجهيز والتشجير والافتتاح. أنشئ مراجعة ميزانية موزعة على المراحل ومراكز التكلفة، ثم أرسلها واعتمدها بحساب آخر. فعّل المشروع بعد التجهيز.

### 2. أمر مواد أو عقد أعمال

افتح «دورة الشراء» ثم «إنشاء». اختر نوع التنفيذ والمورد وعنوان الأمر ومرجع العقد والإدارة وشروط الدفع والتوريد. لكل بند اختر الصنف والوحدة والكمية والسعر والتاريخ والمشروع وبند الميزانية والموقع والمستودع. الوحدة المختارة يجب أن تكون معرّفة للصنف. أرسل المستند واعتمده؛ يسجل الالتزام المالي عند الاعتماد النهائي ويمنع تجاوز الميزانية.

لعقد مقاول، استخدم أصناف الخدمة وكميات قابلة للقياس. يمكن تمثيل بند بقيمة 100,000 ريال بـ 100 وحدة إنجاز ×1,000 ريال للوحدة؛ محضر 50 وحدة يعني قيمة أعمال 50,000 ريال لذلك البند. نسبة تقدم المرحلة في لوحة المشروع حقل متابعة مستقل يُحدث يدويًا، ولا تولد فاتورة تلقائيًا.

### 3. إثبات الاستلام أو الإنجاز

للمواد، افتح «الشحن والاستلام والفحص»، وأنشئ إذن استلام مرتبطًا بالأمر وجدول توريده. أدخل الكمية الفعلية ثم افحصها وسجل المقبول والمرفوض وموقع التخزين. وصول 20 وقبول 18 يتيح فوترة 18 فقط. يستطيع النظام تسجيل استلام آخر للكميات البديلة.

للأعمال، افتح «الفواتير والدفعات» ثم محاضر الإنجاز. اختر عقد الأعمال والبنود والكميات المنجزة وأدخل مرجع محضر أو إثباتًا، ثم اعتمد المحضر بحساب آخر. لا تستخدم إذن استلام مواد لإثبات أعمال المقاول.

المرتجع المقبول الذي سبق فوترته يتطلب إشعارًا دائنًا معتمدًا أولًا. تعكس حركة المرتجع أثر الاستلام والمخزون، وتعكس الموافقة على الإشعار أثر التكلفة الفعلية. إذا سبق دفع المبلغ، يظهر رصيد لصالح المنشأة لدى المورد؛ استرداده نقدًا خارج نطاق هذه النسخة.

### 4. الفاتورة والمطابقة

أنشئ فاتورة من «الفواتير والدفعات»، واختر الأمر ومرجع فاتورة المورد وتاريخها والاستحقاق والبنود والكميات والأسعار. يمكنك تحديد نسبة احتجاز إن وجدت.

اضغط «مطابقة». يقارن الخادم الفاتورة بالأمر والاستلام المقبول أو الأعمال المعتمدة. السعر المختلف أو الكمية التي تتجاوز المتاح يمنعان الإرسال للاعتماد. الإرسال بعد نجاح المطابقة يبدأ المسار؛ عند الاعتماد النهائي فقط تسجل التكلفة الفعلية. احتفظ بمرجع المورد صحيحًا وأرفق فاتورته.

### 5. جدول الدفعات والدفع

من الملخص المالي للأمر أنشئ جدول دفعات بإجمالي نسب 100%. حدد الاسم والنسبة والتاريخ والشرط لكل دفعة. تستطيع فصل تسليم الكمية كاملة عن دفع ثمنها على مراحل.

الدفعة المقدمة تستحق وفق جدولها، وتُربط تسويتها اللاحقة بفاتورة معتمدة باستخدام نوع «تسوية مقدم». التسوية تخفض رصيد الفاتورة والمقدم دون احتساب خروج نقدي جديد. الدفعة العادية مرتبطة بفاتورة معتمدة واستحقاق مثبت في الجدول. شروط الزراعة والضمان والتحقق اليدوي تتطلب إدخال إثبات بواسطة شخص آخر؛ شرط الاستلام يتحقق أيضًا من قيمة المقبول.

أدخل مرجع التحويل أو سند الدفع واطلب الاعتماد. يتحقق الخادم من التاريخ والمبلغ ورصيد الفاتورة وسقف الدفعة وإجمالي الأمر، ويحسب الطلبات المعلقة لمنع صرف المبلغ مرتين. الاعتماد يسجل الدفع داخل النظام؛ لا يرسل تحويلًا إلى البنك ولا يثبت حصول التحويل خارجيًا.

المبالغ المحتجزة لا تُدفع قبل طلب الإفراج عنها وإثباته واعتماده. الإفراج يجعلها مستحقة؛ يلزم إنشاء دفعة مستقلة لها. المستندات المرتجعة أو المرفوضة يمكن إعادة إرسالها من منشئها بعد معالجة السبب؛ يبدأ مسار جديد ويبقى التاريخ السابق محفوظًا.

### 6. المتابعة والإغلاق

من «المركز التشغيلي» اختر المشروع. يعرض إجمالي الميزانية والالتزامات وقيمة المقبول والتكلفة المعتمدة والمدفوع، ثم نفس المقاييس لكل مرحلة. يعرض لكل بند أمر كميته المقبولة مقابل المطلوبة، والمدفوع للأمر، والتنبيه إلى تأخر التوريد أو الفاتورة المستحقة. المدفوع في صفوف البنود هو إجمالي الأمر وقد يتكرر إذا تعددت بنوده؛ لا تجمع هذه الصفوف لاستخراج المدفوع للمشروع.

من الملخص المالي للأمر ترى جدول الدفعات ورصيد كل فاتورة والمقدم غير المسوى. إغلاق الأمر يتطلب اكتمال الكميات والتكلفة والتسوية والدفعات والإفراج عن الاحتجاز وعدم وجود طلبات معلقة. إغلاق المشروع يرفض وجود أوامر مفتوحة أو عدم تسوية التكاليف والدفعات.

## السيناريو التدريبي الموجود

| البند         |        المطلوب | المقبول/المعتمد | الفواتير المعتمدة |      المدفوع |
| ------------- | -------------: | --------------: | ----------------: | -----------: |
| أشجار الزيتون |        20 شجرة |         20 شجرة |      200,000 ريال | 200,000 ريال |
| أعمال تجهيز   | 100 وحدة إنجاز |         50 وحدة |       50,000 ريال |       0 ريال |

ميزانية المشروع 300,000 ريال؛ التزامه 300,000؛ المقبول والتكلفة المعتمدة 250,000؛ المدفوع 200,000؛ رصيد الفواتير 50,000. دفعات الأشجار 60,000 ثم 80,000 ثم 60,000. يوجد طلب دفعة أعمال 50,000 ينتظر المعتمد. سجّل الدخول بحساب المعتمد، وافتح طلب الدفع من قائمة الدفعات واقرأ تاريخه ثم اعتمده لتجربة الخطوة الأخيرة. ستتغير أرقام المدفوع والمتبقي بعد اعتمادك.

## المرفقات والنسخ الاحتياطي

المرفقات مرتبطة بالأمر والفاتورة ومحضر الإنجاز، بحد 6 ميغابايت للملف. التنزيل يمر عبر مصادقة وصلاحيات الوثائق. عند غياب إعدادات التخزين الخارجي، يستخدم الخادم `.data/documents` أو `FILE_STORAGE_DIR`. احتفظ بهذا المسار ضمن النسخ الاحتياطي مع قاعدة البيانات؛ وجود سجل الملف في القاعدة لا يحفظ محتواه وحده.

سكربت الترحيل يحفظ تعريفات الجداول قبل التعديل؛ هذه ليست نسخة احتياطية لصفوف البيانات. للاستخدام الفعلي يلزم نسخ محتويات القاعدة والملفات مع تجربة الاستعادة.

## فحص النسخة

```powershell
npm run check
npm run test:unit
npm run test:mvp:integration
npm run test:mvp-ui
npm run build
```

اختبار التكامل يتصل بالقاعدة الحالية ويزرع سجلات معزولة ثم ينظفها. اختبار المتصفح يحتاج المشروع التدريبي وEdge؛ ينشئ أمرًا وفاتورة ومرفقًا للاختبار وينظفها. لا يعتمد دفعة التدريب المنتظرة.

المؤجل: تخطيط الطلب والتنبؤ وإعادة الطلب، تحسين النقل والمسارات والجمارك، تأهيل وتقييم الموردين الموسع، المحاسبة العامة والتكامل البنكي، دورة العقود القانونية الموسعة، الجدولة المتقدمة والمسار الحرج، والربط مع الأنظمة الخارجية. قبل التشغيل الفعلي، جرّب مشروعًا واحدًا بحسابات وصلاحيات حقيقية وراجع تطابق المستندات مع إجراء المنشأة.
