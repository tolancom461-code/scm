# دليل المرحلة الأولى — المشاريع والمستخلصات

تاريخ النطاق: 11 أكتوبر 2026. الواجهة الافتراضية مخصصة للمشاريع والعقود والمستخلصات ومتابعة ما صُرف للمورد أو المقاول. إصدار سند الصرف يتم في البرنامج المحاسبي، ثم تسجل العملية الفعلية هنا.

## البداية

1. من «تهيئة البيانات» أدخل اسم الشركة وبياناتها والشعار الاختياري، وأضف المشروع باسمه وموقعه.
2. من «الموردون والمقاولون» أضف الاسم والهاتف والبريد والسجل التجاري والرقم الضريبي والملاحظات حسب المتاح. يمكن تعديل بيانات المورد لاحقًا.
3. من «المشاريع والعقود» اختر المشروع والمورد، ثم أدخل عنوان العقد ومرجعه وتواريخه ومدة التنفيذ والضمان ووصف الأعمال والشروط.
4. أضف بنود العقد: الوصف والوحدة والكمية وسعر الوحدة. حدد الضريبة ونسبة ضمان الأعمال المحتجز وغرامة التأخير اليومية حسب الاتفاق.
5. حدد جدول الدفعات: اسم كل دفعة ونسبتها وموعدها ونسبة الإنجاز المطلوبة. يجب أن يكون مجموع النسب 100%. هذا جدول تعاقدي، وليس إثبات صرف.

المبالغ الحالية بالريال السعودي. لا تحتاج هذه الدورة إلى تعريف أصناف أو مستودعات أو WBS أو طلب شراء أو فاتورة وسيطة.

## الترقيم التلقائي

يصدر الرقم عند الحفظ الناجح من محرك مركزي في الخادم، ولا يوجد حقل لتعديله يدويًا:

| السجل    | مثال             |
| -------- | ---------------- |
| المشروع  | `PRJ-26-10-0001` |
| العقد    | `CTR-26-10-0001` |
| المستخلص | `IPC-26-10-0001` |

السنة والشهر ميلاديان بتوقيت السعودية، وفق وقت إنشاء السجل، وليس تاريخ تنفيذ الأعمال الذي تدخله. لكل رمز عدّاد سنوي مستقل على مستوى النظام؛ يستمر عبر الأشهر ويبدأ من 1 في السنة التالية. مثال: `CTR-26-11-0002` ثم `CTR-27-01-0001`. التسلسل لا يُقص عند تجاوز 9999. الرقم الكامل فريد وثابت، ويُحفظ المستخلص المرفوض برقمه. قد توجد فجوات في الأرقام، ولا يعاد استخدام رقم صدر لسجل محفوظ.

يظهر رقم المشروع في التهيئة وقائمة اختيار المشروع ونتائج البحث والعقد والمستخلص. يحتفظ المستخلص برقمه المستقل ويعرض رقم العقد الداخلي ومرجعه الخارجي ورقم المشروع، وكذلك ترتيبه داخل العقد. يشمل ترتيب المستخلصات السجلات المرفوضة أيضًا، حتى لا يتغير ترتيب المستخلصات التالية عند رفض مستخلص.

الترحيل 0011 يضيف أرقامًا للمشاريع التي لم تكن لها أرقام، حسب تاريخ إنشائها بتوقيت السعودية. أرقام العقود والمستخلصات الصادرة سابقًا تبقى كما هي. الصيغة ذات خانتين للسنة مخصصة للسنوات 2000–2099؛ يلزم توسيع الصيغة قبل دخول قرن جديد لمنع التباس السنة.

## إعداد المستخلص

من تفاصيل العقد اختر «إعداد مستخلص». أدخل التاريخ، ثم نسبة الإنجاز التراكمية أو الكمية المنفذة حتى الآن لكل بند. أدخل **إجمالي** أيام التأخير حتى تاريخ المستخلص، وأي خصم إضافي يخص المستخلص الحالي مع سببه.

يحسب البرنامج قيمة الإنجاز إلى تاريخه، ويطرح ما سبق اعتماده، ثم يحسب الضريبة والضمان المحتجز وغرامة التأخير الجديدة والخصم الحالي وصافي المستخلص. تقريب الضريبة والاحتجاز يعتمد على الفرق بين الإجماليات التراكمية، حتى لا تتراكم فروق الهللات عبر المستخلصات المتعددة. لا يسمح بتراجع الكميات أو تجاوز كمية العقد أو صافي سالب.

يوجد مستخلص واحد بانتظار الاعتماد لكل عقد. لا يدخل المستخلص في المستحقات قبل اعتماد مستخدم آخر له؛ لا يستطيع منشئ المستخلص اعتماده حتى لو كان مديرًا. المستخلص المرفوض محفوظ مع سبب القرار، ويمكن إنشاء مستخلص بديل. المستخلص المعتمد لا يعدل ولا يحذف من هذه الواجهة.

مثال حسابي مأخوذ من العينات، وليس سجلًا تشغيليًا: 141 م² × 24 ريالًا = 3,384 ريالًا. إنجاز 90% بقيمة 3,045.60، وضمان 20% بقيمة 609.12، وغرامة يومين بقيمة 400، وخصم 414؛ الصافي 1,622.48 ريالًا.

## عمل المحاسب

افتح «حسابات الموردين والدفعات». يظهر لكل مورد ولكل عقد:

- مجموع المبالغ المصروفة والمسجلة فعليًا.
- المستحق المتبقي: صافي المستخلصات المعتمدة، مضافًا إليه الضمان المفرج عنه، بعد خصم المصروف.
- الضمان المحتجز الذي لم يفرج عنه، منفصلًا عن المستحق للصرف.
- الدفعة القادمة: اسمها وموعدها والمبلغ التعاقدي المتبقي فيها والمبلغ الجاهز للصرف حاليًا.

المستحق المتبقي **لا يساوي** كامل قيمة العقد ناقص المصروف؛ الأعمال التي لم يعتمد مستخلص لها لا تصبح مستحقًا للصرف. راجع جدول الدفعات لمعرفة المبالغ المخططة، وراجع العقد لمعرفة قيمته الكاملة.

تصبح الدفعة جاهزة عندما يحل موعدها ويتحقق إنجازها المطلوب ويوجد رصيد مستخلص معتمد. المبلغ الجاهز قد يكون أقل من مبلغ الدفعة التعاقدي بسبب الاحتجاز أو الخصومات. لا يدعم هذا المسار صرف مقدم قبل وجود مستخلص معتمد.

بعد إصدار السند وصرف المبلغ من برنامجك المحاسبي، اختر «تسجيل مبلغ مصروف» وحدد المستخلص والدفعة وسجل **المبلغ الفعلي والتاريخ الفعلي ورقم سند الصرف المحاسبي** والملاحظات. يمكن صرف جزء من الدفعة ثم تسجيل باقيها بسند آخر. لا يسمح بتاريخ مستقبل أو صرف يتجاوز رصيد المستخلص أو الدفعة المتاح، ويرفض تكرار رقم السند ضمن السنة الميلادية نفسها في هذه الدورة.

يمكن إرفاق نسخة السند من تفاصيل عملية الصرف. تسجيل العملية هنا يحدث الأرصدة، ولا ينشئ سندًا أو قيدًا أو تحويلًا في برنامج المحاسبة.

## الضمان والطباعة والمرفقات

الإفراج عن ضمان الأعمال إجراء مستقل بصلاحية مالية وسبب مسجل. يضيف المبلغ إلى المستحق دون تسجيله كمصروف. بعد الصرف الفعلي يسجل المحاسب عملية من نوع «صرف ضمان مفرج عنه» مرتبطة بالمستخلص.

من تفاصيل العقد أو المستخلص اختر «طباعة»، ثم استخدم طباعة المتصفح أو الحفظ بصيغة PDF. تعرض الطباعة بيانات الشركة والبنود والمبالغ والشروط، وحالة المستخلص. يمكن رفع ملفات للعقد والمستخلص والصرف؛ الحد الحالي للملف 6 ميغابايت، والتنزيل يتطلب تسجيل الدخول والصلاحية المناسبة.

## المستخدمون

من «المستخدمون والصلاحيات» جهز حساب إعداد ومتابعة، وحساب اعتماد مستقل، وحساب محاسب. الصلاحيات الأساسية:

| العمل                  | الصلاحيات                                                   |
| ---------------------- | ----------------------------------------------------------- |
| إعداد الشركة والمشاريع | `p1.company.view`, `p1.company.manage`, `p1.projects.create` |
| الموردون               | `suppliers.view`, `suppliers.create`, `suppliers.edit`      |
| العقود والمستخلصات     | `p1.contracts.view`, `p1.contracts.create`, `p1.certificates.create` |
| اعتماد المستخلص        | `p1.certificates.view`, `p1.certificates.approve` |
| المحاسب                | `p1.payments.view`, `p1.payments.record` |
| الإفراج عن الضمان      | `p1.retention.release` |
| المرفقات               | `documents.view`, `documents.upload`                        |

المحاسب الذي يملك صلاحياته فقط يرى شاشة الحسابات والدفعات مباشرة. المدير يملك الصلاحيات الإدارية، لكن قاعدة استقلال اعتماد المستخلص تظل سارية عليه.

اختر الدور من القائمة المنسدلة عند إضافة المستخدم أو تعديل بياناته، ثم خصص صلاحياته الذرية ومشاريعه في النموذج نفسه. يمكن أيضًا إدارة السياسة من «مركز الصلاحيات». اختيار قالب لا يمنع سحب صلاحياته لهذا المستخدم، ولا يغير القالب أو بقية المستخدمين. الصلاحية وحدها لا تمنح وصولًا إلى مشروع غير محدد، والحساب دون سياسة يبدأ مغلق الصلاحيات. دليل الأدوار والحماية والتطوير المستقبلي في [POLICY_CENTER_GUIDE.md](POLICY_CENTER_GUIDE.md).

في جدول المستخدمين توجد إجراءات «تعديل البيانات»، و«تغيير كلمة المرور»، و«تعطيل المستخدم» أو «تفعيل المستخدم». تعديل البيانات يشمل اسم الدخول والاسم والبريد واللغة، مع منع تكرار اسم الدخول. تغيير كلمة المرور يتطلب 12 حرفًا على الأقل وتأكيدًا مطابقًا، وينهي الجلسات السابقة للحساب. عند تغيير كلمة مرور حسابك ستعود إلى شاشة الدخول؛ استخدم الكلمة الجديدة.

تعطيل المستخدم يمنع تسجيل الدخول وينهي جلساته دون حذف سجلاته. إعادة التفعيل تسمح بدخول جديد ولا تعيد الجلسات القديمة. لا يمكن تعطيل حسابك الذي تستخدمه حاليًا. إجراءات إدارة المستخدمين لها صلاحيات مستقلة: `users.edit` و`users.password.reset` و`users.status.manage`، إضافة إلى `users.view` لعرض الصفحة. إدارة حساب يحمل دور المدير متاحة للمدير فقط؛ لا تمنح أزرار تعديل البيانات صلاحية تغيير دور الحساب.

## البيانات السابقة والتشغيل

السجلات السابقة محفوظة ويمكن الوصول إليها من «الدورة السابقة». موردو النظام مشتركون، لكن المشاريع والعقود والمستخلصات والدفعات الجديدة محفوظة في جداول المرحلة الأولى؛ أرصدة هذه الواجهة تخص عملياتها فقط. لم تنقل الدفعات أو الأرصدة القديمة تلقائيًا. عينات PDF استُخدمت لفهم الوظائف والحسابات، ولم تُدخل كعقود فعلية.

الترحيل `0010_lying_toad.sql` يضيف ستة جداول وعلاقاتها وفهارسها دون تغيير جداول الدورة السابقة. أُجري على القاعدة الحالية. ملف مخطط القاعدة السابق ليس نسخة احتياطية لمحتويات الصفوف.

تشغيل التطوير بعد تجهيز حزم المشروع و`DATABASE_URL`:

```powershell
npm run dev
```

تشغيل النسخة المبنية:

```powershell
npm run build
$env:PORT = '3050'
npm run start
```

استخدم حسابك الحالي. لا يلزم زرع بيانات تدريبية لبدء هذه المرحلة. لترحيل قاعدة أخرى استخدم `npm run db:migrate` قبل التشغيل. الملفات المحلية، عند استخدام التخزين البديل، محفوظة داخل `.data/documents`؛ احتفظ بها مع نسخة القاعدة عند نقل البيئة.

هذه المرحلة لا تشمل تعديل العقد بعد إدخاله أو عكس الصرف المسجل أو الربط التلقائي بالبرنامج المحاسبي. تحقق من البيانات قبل حفظ العمليات الفعلية. الاختبارات المنفذة ونتائجها موثقة في `TESTING.md`.
